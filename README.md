# Sri Vishnu Teja Books, Xerox & Cool Drinks

Pickup-only web store and xerox service portal for **Sri Vishnu Teja Books, Xerox & Cool Drinks** in Railway Kodur, Andhra Pradesh.

## Project Structure

- `web/`: React 18 + Vite + TypeScript web application with Tailwind CSS, Three.js 3D viewers, Firebase, and Supabase.
- `tools/`: Image generation and catalogue processing scripts.
- `shop_pics/`: Original store photography and product cutouts.
- `ui/`: Reference designs and UI color palette.
- `stitch_sri_vishnu_teja_stationery_webstore (1)/`: Original design export.
- `PROJECT-HANDOFF.md`: Full project audit, architecture map, and development roadmap.

## Getting Started

```bash
cd web
npm install
npm run dev
```

To build for production:
```bash
cd web
npm run build
```
